# START HERE — pierwszy APK

1. Utwórz prywatne repozytorium GitHub.
2. Wgraj **zawartość tego katalogu** do głównego katalogu repozytorium (nie dodatkowy folder nadrzędny).
3. Wykonaj push do gałęzi `main`.
4. Otwórz zakładkę **Actions** → workflow **Android APK**.
5. Po poprawnym buildzie otwórz run → sekcja **Artifacts**.
6. Pobierz `CRM-Mobile-Bridge-0.8.1-debug`.
7. W archiwum artefaktu będzie `CRM-Mobile-Bridge-0.8.1-debug.apk` i plik SHA-256.

Debug APK nie wymaga żadnego klucza podpisu użytkownika i ma pakiet `pl.usundlug.crmbridge.debug`.

Wersja release: patrz `docs/RELEASE_SIGNING_GITHUB.md`.
